chromebook catastrophe


So I wanted to write an entry over something that already happened last year at almost the same time as I am writing this. All I had was this heavy gaming laptop that started to see some damage as I carried it around everywhere for college.


That was until I realized I had a spare laptop to use that I got for free. The problem was that ...it's a chromebook... so knowing how chromebooks operate, I acutally couldn't make much use out of it anyways. That was until I decide to take on the journey of eradicating ChromeOS from the system and replacing it with Debian. Below are a list of guides I used to accomplish this successfully.


  • https://www.quantulum.co.uk/blog/linux-on-a-chromebook/
  • https://www.quantulum.co.uk/blog/debian-on-a-chromebook/
  • https://docs.mrchromebox.tech/
  • https://docs.chrultrabook.com/

For anyone willing to try this, know that this is a huge risk and will void any warranties. For me, I had nothing to lose.


On a regular computer, you just uhh download the thing, put in on the flash drive, boot from it, and install and done right? Since chromebooks are so DAMN secure, you must cross multiple hurdles to be even able to install an OS, so firstly, we must enable...


developer mode

... well not yet actually... First we need to enter recovery mode by holding ESC and REFRESH. Then we choose "Boot from internal disk". Do note that everything will be reset. From here we "browse as guest" and go into a web browser... chrome of course... it's a chromebook. I want to note, this guide will help you better than I will on this blog. I'm just reflecting.


the firmware script

Now we are going to use "MrChromeBox's Firmware Utility Script". So I ended up doing first RW_LEGACY then the Full ROM after, most likely because I realized that wasn't what I wanted. Before going further, I had to make sure my chromebook would work with the script (and later stuff). Then I could continue. So uhh we use the web browser to uhhh "open a command prompt" you know like windows (technically its a crosh shell). Then you run this script.

"cd; curl -LOf mrchromebox.tech/firmware-util.sh && sudo bash firmware-util.sh"


I run that script a lot and I still do to check for firmware updates. When the script loads as it should, there are 4 options and you will only have access to 2 (WP is foreshadowing for future suffering). I went with option 1 for now. Install the firmware, and input this thing afterwards and run.

"sudo crossystem dev_boot_altfw=1"


If nothing happens, good, you can just "sudo reboot". From here, you can choose to dual boot but that is not the path I took. I wanted the whole Linux, no ChromeOS. This mean't that I needed to disable..


write protection

This is the worst part of the whole process and is completely dependent on what chomebook you have. There are three methods to disable write protection and only one of them worked with my chromebook (the worst option).


  • Disconnecting the Battery
  • Bridging a Jumper
  • Using a SuzyQable?

Huh? What's a SuzyQable? Doesn't matter because you can't buy one anymore right? Right? Right? Right? RIGHT?! RIGHT?!!!!


Ok so I did the first two options first to see if they worked (they didn't). So I had to do the third option which was split into two parts. First you must enable Closed Case Debugging. Remember the guides I linked? Specifically the one that underlines "disable write protection"? I used those, well except for uh, getting the cable part but well get to it soon. So after that process of enabling CCD, I now needed a SuzyQable. But uhhh what is a SuzyQable? Well simply it's a ChromeOS Debug Cable specifically for, well, exactly what we are doing. But you see they don't really sell them so like after searching and searching and searching for days for a cable that I can order, I found something close. It's an adapter but... it has to work with my phone charger cable right? .....it did. So now I could continue through the rest of the instructions very carefully like I have been doing. Also there was another step like "Disable AP RO Firmware Verification" but I don't remember doing that.


the firmware script part 2

Ah free at last (false). Now we go back to the script to double check if WP is off and indeed it was. Another thing to note was I also had to buy like two flash drives. One for the required chromeos backup and the other for my choosen linux distro. So I flash the UEFI Full Rom Firmware as per the instructions (waiting included). And now all that's left was to install the OS simple right? ...............................no


debian does not install

So I booted up the live USB of Debian 12 and went through the install process, choosing the largest partition to put Debian on (there were 8+ separate partitions, to this day I don't know what they are). So it's installing right up until I get an error and now I'm like what the hell do I do now? It's not like I can fix the partition now right? .... I can... so there's is thing I found called GParted and you can put it on another usb (see how many usbs i had to buy bruh) and change all of the partitions at ease and change file system formats and everything.


Booting up GParted LIVE (heh it's on debian), I find that big partition and carefully contemplate my next moves. From what I remember, I chose to remove that whole partiton, and either I left it at that or I created a new partition with the file system it wanted (ext4). Either way, I applied my changes, waited, rebooted into the live usb for debian and.... it ... worked!


the end

and now I boot up into my fresh, debian 12 xfce, on my wretched chromebook.........until.....now... the audio doesn't work.... the keypad doesn't work..... bluetooth is missing.... why is it failing to boot sometimes?..... the whole damn thing freezes when I have chrome and discord open.....the laptop lid doesn't shut the computer off........... WE ARE NOT DONE YET WE ARE NOT DONE YET WE ARE NOT DONE YET


debian is still broken

Ok first, remember it's still not an actual regular pc, it's a chromebook, we made serious modifications to it already and there is still more to be made. I won't be covering everything I did here because this blog is already abnormally long but I will cover the most important things I had to fix after install. Afterall, with most linux distros, you have to do that anyways.


So using this place now and this one too to fix common issues, I wanted to fix audio first (longest to fix for some reason) and the keyboard (cause it's a chromebook keyboard).


I begin the setup and execution of this script until... my board isn't supported???? So for like the first time ever I open a GitHub issue to add the board (fyi, each chromebook has a different board name). So a month passes and it's finally configured to work on my chromebook. I run the script again after updating it and.... it's still not working.... so. Now I create another issue and have a chat back and forth over steps I must take, things I must install, logs to send over, eventually after randomly configuring the volume profile to Pro Audio, it worked... finally.


While all of this stuff happened over months, I ran the keyboard script and it worked without issue.


the real end

So now I fix everything else missing by downloading whatever is missing like a boss and from that point on, tt was operable!!! I take my chromebook everywhere for work and leave my gaming laptop at my place hooked up to a second monitor, keyboard, mouse, it's basically a fake desktop if you think about it.


Anyways, my blogs are not supposed to be this long, this is very much an exception. If you took the time to read this.... thanks....

calculus struggles


This year in the month of March, there was one thing I knew for certain after taking the second exam of my Calculus 2 course:


I had failed two exams and I will not pass.


So... I took a W and went through the rest of my semester with dread and confusion...... well a lot of things were running through my head that weren't just limited to math but I am not ready to discuss that yet. Good thing I was able to finally make new friends around that time so when looking back I see it as a bit of a tradeoff sometimes.


Now fast forward to November and almost every exam I took this time was at least 98% and I am passing with flying colors. So... what the hell happened??


In this blog entry, I'm going to sum up my journey so far in college and share it to you stranger... well... specifically math fundamentals... well more specifically... calculus 1 and 2... ehh hopefully if you are in college or going through some rough shit right now, maybe you can gain something from my yap.


Before I begin, I want to let any potential blog crawlers know that I will be going over some topics in math that you will not understand and that's ok. I'll do my best to make only what is important in the context of the blog make sense and if you already went through calculus... well... that's awesome dude like uh hit me up or something lets talk bro... or like don't do that... OR DO!!


calculus one

I took Calculus 1 in the Fall the year before this one (2024) and was presented with minimal issues whatsoever. As someone who has a love-hate relationship with math and has grown quite accustomed to it, I digested a lot of the material very well and was quite surprised that I passed the final exam with flying colors (like nearly aced it type of flying colors). It can also be attributed that I was lucky to have such a wonderful professor for the course and was excitied to attend class every day at 8 in the morning. Oh those were the times. I remember how excited I was to learn completely new and different math, never seen before in my high school days.


Small note, towards the end of the course we tapped into integration, fundamental theorem of calculus, and most importantly, substitution. I'll try to explain these concepts really quickly. Through the wonderfuly magic of integration, we can find the area under any curved line by cutting it up into many many thin rectangles and adding it all up, effectively approximating the total area under that curve. Look up a picture and you'll see what i'm talking about... "add a picture?" nah I don't feel like it sorry. Anyways, Fundamental Theorem of Calculus simply is a way to help us find a section of an area under a curve with integration because doing math the long way sucks, and substitution... well... i'll explain that in the next section. All of this was to prepare students for Calculus 2 as I remember my professor saying. It also sounded like Calculus 2 was going to be very difficult. Since I did just fine with the first Calculus, it's not like this one was going to be bad right?


calculus two (part one)

Well of course it wasn't all fucking right was it, I already told you what happened bro I got a W! No it does not mean Winner it actually mean's LOSER. Anyways, let me get into the details of what happened.


For context, I had chosen one professor for this course and ended up with a completely different one by the time I found out the first day. I quickly pull up this guy's rate my professor scores like a boss and uhhhhhh it was in the middle... so I stayed...


First lecture was substitution... and is the easiest thing out of the entire course... I tell ya, they pack so much shit into the course no wonder students fail, because they can't absorb all that material fast enough. I'm sure it's more than that but anyways, substitution is... well... I lied, I can't really explain it in simple terms so like imagine a normal quadratic equation right? Totally solvable with quadratic formula. But what if the quadratic had sine or cosine in it for some odd unexplainable reason? This is where you take that sine or cos and make it equal to your favorite letter that isn't x. Now later we put this back in the equation but throughout the process of substitution, we end up canceling out terms we don't like so it's easier to solve. NOW THAT WAS A SUPER OVERSIMPLIFICATION! From here on out, I not writing entire calculus lecture notes for your reading pleasure.


So like I said, "easiest thing out of the entire course". Everything else there was quite hard to grasp and even though I thought it clicked with me like calculus 1 did, I realized that I have been using examples and notes so much and all the while not seeking help and not actually learning the actual methods to heart in the homework problems. So when the first exam showed up, I though I did ok but ended up coming out with a stab in the back. I think it was between 63-53. With this realization I was starting to worry. First exam material was all about finding the volume of solids which doesn't sound hard until you actually do the problem and realize "ok where are my bounds of integration? where's the graph? how do i graph this? what method do i use? how does shell method even work? i forgot how to substitute how do i do it again? what is my radius? how do i rotate respect to y? hooke's law? i thought this was solids of revolution not physics one."


Next exam material was all integation techniques, so no more volumes of revolution hooray! Side note but the professor couldn't explain conceptually how things work, he would show you through examples but he went so fast it didn't matter. Also his graphs were not easy to observe so there's that too. Why am I saying all this? Because it mean't I had to teach all the material myself. I found this out too late and also like I wasn't using helpful resources available for math so that's another problem too. Learning the material wasn't all too bad and was easier than the last exam.... but when it was time for the exam.... I had lost all hope...


the first failure

After taking the exam, I already knew somewhat how my grade would be. I checked to see what I would need to pass Calculus 2.


A miracle.


My only hope was the final replacing my lowest grade. But... I had no hope left... The deadline to withdraw was in two day and I decided to take it so I wouldn't wake up every morning to math (attendence was mandatory). At this time, my degree was in Computer Science and I was barely in Programming 1 (I had taken a lot of beginner coding courses already fyi) and now I was considering a whole lot of things... and also there were other stuff going through my head that I am still not ready to discuss... but importantly I was considering switching majors for a multitude of reasons that would take forever. After I had withdrawn from the course, the rest of the semester felt approachable and I had felt a weight disappear from my shoulders, but I still felt guilt and shame. Through my thinking and research, I have realized that I had a better future somewhere else then where I was now and I wanted to pursue it. It was then that I switched to Electrical Engineering. Almost unexpectedly, It would make sense that I would give up and chose something easier but that was not the case here. I wanted something harder, challenging, and much more rewarding than programming a bunch of code or whatever the hell is happening in Computer Science right now.


Continuing the rest of the semester like normal, there was one thing I was happy about and that was finally finding a group of friends in college. I felt a little better, a little less lonely in this sick world.


calculus two (part two)

Time skip to next semester, I started out very strong the first two weeks. It felt as if everything that I had been doing this semester completely surmounted how much I did the past two semesters. It was the beginning of something but I didn't know it yet. Tried getting a better professor this time but fate decided I was going to get an ever worse professor... or so I thought. Oddly enough I understood it more from him, maybe it was because he made us attempt integrals in class. Or it could be that I already learned it and it's easier to learn the second time. Either way, I prefered him more. Additionally his exams were surprisingly easier that my other professor's exam but that's for later. Anyways this time, I completely changed the way I approached Calculus 2 altogether.


So for Calculus 1 & 2, I had used physical notebooks for my studies. This time I went the iPad route instead and I found it much more practical and less of a headache when doing the homework problems. Picture this, notebooks only have a certain amount of pages and size and stuff, eventually you will run out of space and when it comes to math, it's even faster. On my iPad, I can organize my notes into sections and it's like one infinite page of math (until it crashes). Additionally, using color helped me understand my math a whole lot more.


While attempting my homework problems, I would no longer do them by myself. Instead, I would be in a room full of math tutors for 4-5 hours a day asking for help to my hardest problems (and occasionally going to professors office hours). No day was spent without doing Calculus 2. This was the key to my success. By the time the first exam came around, I had done all that I can to prepare and I was worried sick if I could still do it. I have completed all homework problems, all exam review problems, AND worked on half of the extra exam review problems. I knew all the in's and out's of Solids of Revolution, Hooke's Law, Substitution, and the like. I also had 10 bonus points from the review problems AND the professor provided a sample practice exam and a formula sheet. I could not mess this up.


... By the time I finished the first exam, there was no time left. However, all the problems were attempted and completed within 50 minutes. Two days had passed and at 2 in the morning, the first exam grade was released......


It read 101


I had never felt so proud of myself for the longest of time, full of doubt and self-loathing, i have once again regained my confidence. But the cynical critic steps right in, knowing that there are still 2 more midterm exams left. There was still weight on my shoulders, but it felt like the heaviest one was gone. From there, I continued my strategy like before. To be honest, it was easier learning all of the material the second time, but the homework problems were still difficult. This didn't mean they weren't impossible and I knew that this time around.


The second exam comes and goes, I still felt sick to my stomach. When the grade comes in, there was only a -3 point difference. Passing Calculus 2 was in reach and by not very far. I felt amazing, unstoppable, confident. All that was left was unseen territory, Infinite Series & Power Series. In Calculus 2, we have been learning integration the whole time and now for the rest of the course, it was a complete introduction to a new form of math. Some had said this is the hardest part of the course and some have said the opposite. As I went through it, it was slightly difficult to pick up on, but I had pretty good explanations from my tutors and somewhat from my professor. Ultimately, it came down to how I approached the problem myself and how I did it.


The third exam came around and although I got a lesser grade (still passing), there was one thing I knew after taking it. I COULD NOT FAIL!


series finale

Although Power Series was very tricky at first, the end was in sight. The final exam wasn't a huge threat and I did just fine. Even though I know it will get harder (Calculus 3 and beyond), anything feels possible if I sink enough time and effort into it. I feel one step closer to becoming a math wizard, or maybe I already am, or maybe that's why I like wizards, eh I don't care and it probably doesn't matter too much. I'll save it for the self-loathing sessions and go like "why do I like this? why am I this way? am I valid? why do i hate myself? do they know that-" you know shit like that... what was I talking about? Oh yeah, I passed. But why did I write all this? Because I wanted to share with any readers proof that you can do anything you want if you put in the time and effort. It won't look pretty but you can get there and I found out that it's possible. And it really applies to anything, not just math. I hope that all of this was worth your time reading and I also just realized that long ass blog entries are normal.

gaming & the paradox of choice


The phrase "paradox of choice" comes from said book named exactly that and, wouldn't you know, it means that too many choices is... very overwhelming. I just realized that today and that a book like this exists. But I'm not typing all this with my cold dead hands over a book I never read. I want to just rant over a small little issue I have had for a while.


I hardly ever finish video games I buy.


Now I'm pretty sure this is pretty common amongst fellow gamers, but like I'm wasting money over products I don't completely see and it's like over so many factors. Thankfully, I have another to add to this list after finding out about a book called "the paradox of choice: why more is less". Heh..... wouldn't you know how much this applies.

Believe it or not, and you will, at the time of writing I have 162 games and counting. Of course, some of them are free and should be ignored because, well, uh, I didn't buy them, and uh, it's probably multiplayer AAA slop right? SO FIRST THE ELEPHANT IN THE ROOM!!! It appears I have too many options, and this causes anxiety, which is already a huge problem for me anyways. Like let me show you what I got.



So there are some stuff you may not recognize and stuff that you do. You might as well say "oh my god there are so many great games you have" and that is exactly the problem. I have too many! Like rdr2 is a great game but I can't get myself to play and finish it. the paradox of choice & gaming (ft. refunds)

It's clear now that I gain and lose interest in all the games I have (and used to have because I refunded them on time). I have so many options that I should start limiting them and set short, simple goals. Although I can't completely fix this small issue, I can just do my best and play what I find interesting right now and reduce my options. Simply put, just install games you are actively playing and uninstall the ones you don't play or already completed (I still need to remove freddy fazbear).
